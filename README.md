# Fooled at First Sight?

**Eye-Tracking, Memory Recall, and Psychometric Modeling of Real vs. AI Image Judgments**

Companion page for a research poster presented at the UNR Graduate Poster Symposium, October 27, 2026.

**View the page:** https://your-username.github.io/fooled-at-first-sight/

## About

Generative AI can now make images people can't reliably tell from real photos. This study used eye tracking and two recognition memory tests to examine how people look at, judge, and remember AI-generated versus real images.
